# 必要項目の作成・編集・公開（2.3.0）

①の一括登録後、「必要項目の作成・編集・公開」で資料を選択する。助成金名・年度を設定し、各資料を順番に解析する。項目名・入力形式・必須・使用する・説明・選択肢・資料根拠・転記先・表示条件を編集する。AI候補の一致はIDまたはNFKC正規化項目名で検出し、候補から統合／別項目／不採用を明示する。意味の違いは管理者が確認する。公開済みの項目IDは削除せず無効化する。

## AI接続（本人による初回設定）
GASのプロジェクト設定→スクリプトプロパティで `GEMINI_API_KEY` と `GRANT_AI_MODEL` を設定する。モデルは当該アカウントでPDF・OfficeとgenerateContentを利用できるモデルIDを指定する。秘密値は画面、レスポンス、リポジトリ、ログに出力しない。API接続時にUrlFetchの権限承認が必要になる場合がある。GASとDrive中心の構成で、AIの料金・利用枠は接続アカウントの設定に従う。無料を保証するものではない。

資料をGoogle Gemini APIへ送信するチェックを付けて実行する。解析は1件15 MB以内。PDF/DOCX/XLSXの元ファイルをinlineDataで送る。モデルの対応形式に依存し、不対応や429等のエラーは明示して止める。エラー本文やAPIキーは出力しない。成功した資料は同じページでは再解析せず続きから実行する。画面を閉じる前に下書きを保存する。AIは見落としや誤認があり得るため、根拠・選択肢・全資料の確認が公開の前提。元の見本の個人値は候補に返さないよう指示するが、管理者が最終確認する。

## 公開と会社リンク
下書きプレビューは管理者のみ。送信不可。下書き保存と公開を分離し、公開時点の定義を保存する。
- 今後だけ：新規リンクは新しい公開版。既存の会社リンクは従前の版を維持。
- 未提出会社にも：以前発行済みの未提出リンクにも更新版を適用。入力中に更新されると送信は拒否され、再読み込みを案内。
- 特定会社だけ：当該項目定義に属する未提出・有効な案内のみ指定でき、他社・一般公開版は変更しない。
④の助成金選択肢に公開済みの項目定義が追加される。既存women-r8の固定フォーム・リンクはそのまま保持し、新方式のフォームは別の選択肢になる。初回は新方式のリンクを発行する。旧固定フォームへの自動置換は行わない。

回答・添付PDF・当時の項目定義を指定Drive保存先へ保存。添付は合計20 MB。受付後は二重提出せず同じ受付IDを返す。②の申請一覧・③の転記準備へ接続。③の実際のWord/Excel/PDFへの自動転記は従来どおり未実装。提出後の追加回答リンク・保存済み書類の再生成・自動通知は今回対象外。提出済みレコードは変更しない。

表示条件は一段（他の条件付き項目への依存や循環は不可）。従業員の人数分追加などの繰り返しグループは新方式では未対応。旧固定フォームの従業員機能は維持。
