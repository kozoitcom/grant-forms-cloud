# 助成金資料の一括アップロード

①の一括アップロード欄で、PDF・docx・xlsxを複数選択、またはまとめてドラッグ＆ドロップできる。後から選択へ追加できる。1件20 MB・1回30件・合計50 MBまで。

ファイル名から種類の候補を表示するが、AIによる内容解析ではない。募集要項、空欄様式、記入済み見本の種類を管理者が確認する。募集要項はPDF。空欄様式と見本は片方だけでよい。

既存助成金を選んだ場合、書類と種類を明示指定したファイルはアップロード完了後に様式設定へまとめて反映する。申請者アップロード不要フラグや他の書類設定は保つ。以前のファイル自体は削除しない。新規助成金と「その他」の書類は資料フォルダへ保存し、未実装の動的フォーム・AI解析を実行したことにはしない。

## 保存と再試行

- ファイルは逐次アップロードし、画面に進捗を表示する。
- requestIdにより開始処理を冪等にし、ファイルのサイズ・シグネチャ・SHA-256を確認する。
- 同じ画面で再試行した場合、保存済みの同一ファイルは再作成しない。別内容への置換は拒否する。
- 全ファイルの保存が終わるまで既存の様式設定へ反映しない。
- 選択をクリアしても、Driveへ保存済みのファイルは削除しない。
- 再試行のファイル選択情報は現在の画面内だけに保持する。画面を閉じた途中登録は「保存途中」として一覧に残る。
- 保存先は専用の非公開Driveフォルダ。一括登録単位のJSONに分類・ファイル参照・保存状態を保持する。
- 大きな様式設定はDriveに保存し、従来のScript Properties形式を読み取り互換で維持する。

管理者限定のAPI: getGrantMaterialCatalog、beginGrantMaterialBatch、uploadGrantMaterialFile、completeGrantMaterialBatch、listGrantMaterialBatches。

既存の個別様式アップロードと以前の募集要項下書きは維持する。
